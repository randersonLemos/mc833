# Task 05 — Firewall Rules

## What this task does

Applies iptables rules to enforce the security policy:
- Block Polo 1 ↔ Polo 2 (bidirectional)
- Block Polos and admin from accessing srv_db
- Block Polos and admin from accessing each other
- Block the internet from initiating connections to internal networks
- Allow replies back in (stateful firewall)
